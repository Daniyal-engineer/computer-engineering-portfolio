## Featured Engineering Projects

**1. MUHAFIZ: Autonomous Visitor Guidance Robot**
My flagship R&D project is an autonomous mobile robot designed for visitor guidance and waste awareness. Built on a custom 40x40 cm chassis, MUHAFIZ utilizes a powerful NVIDIA Jetson Nano and ESP32 architecture. It features structured light 3D tracking via an Xbox 360 Kinect sensor, a 7-inch touchscreen interface, and a robust 12V power management system integrating custom buck converters. This project highlights my ability to merge spatial vision with complex hardware ecosystems.

**2. Autonomous Line-Follower & Maze Solver**
I developed an intelligent, microcontroller-based mobile robot capable of navigating complex mazes. Utilizing an Adafruit Motor Shield and an array of infrared sensors, the system relies on highly optimized C++ code implementing the Left-Hand Rule algorithm for autonomous pathfinding and real-time obstacle resolution.

**3. Digital Logic & Computer Vision Implementations**
Beyond robotics, this repository includes detailed explorations into digital logic and image processing. I have designed combinational logic circuits, including gate-level and behavioral modeling of full adders in Verilog. Additionally, my MATLAB scripts demonstrate advanced digital image processing techniques, such as matrix padding and unsharp masking.
